最值得做的不是单纯再加几个“Copy XXX”按钮，而是把它设计成一个 “针对选中请求的复制/导出体系”：顶部有统一入口，右键菜单就近取用，快捷键覆盖高频动作。这样你从这个日志查看器跳到 Bruno 时，动作会很顺。

建议的主方案：在 Inspector 的 Request 顶部，把现在的 Copy cURL 扩成一个 Copy 菜单按钮，Send Again 保留在旁边。
也就是把 LogDetailView.swift 里的 requestActions(for:) 从“单按钮”改成：

 - Copy（Menu / MenuButton）
 - Send Again
 - 可选：Open in Bruno / Export .bru（后续再做）

Copy 菜单里建议放这些项，按你去 Bruno 手动填单的顺序排：

 1. Copy URL
 2. Copy Query Parameters
 3. Copy Query Parameters as JSON
 4. Copy Headers
 5. Copy Headers as JSON
 6. Copy Body
 7. Copy Body as Pretty JSON（仅 JSON 时启用）
 8. Copy cURL
 9. Copy Full HTTP Request Summary（method + url + headers + body，适合一次性贴给别人）

这样比“每个区域放一个按钮”更干净，也更符合你现在 Inspector 顶部 action bar 的结构。

我会这样分：

1. Inspector 顶部：主入口

放在 requestActions(for:) 里：

 - Copy URL
 - Copy Query Parameters
 - Copy Headers
 - Copy Body
 - Copy cURL
 - Send Again

这是最重要的一层，因为用户已经进入“看详情 / 准备复现”的上下文了。

2. Inspector 各 section：就地右键

你现在 Request pane 里已经有这些块：

 - Request Overview
 - Request Headers
 - Request Body
 - cURL

建议每个卡片内容都支持 .contextMenu：

 - URL / Overview 卡片
 - Copy Full URL
 - Copy Host
 - Copy Path
 - Copy Query String
 - Copy Query Parameters as JSON
 - Request Headers 卡片
 - Copy Headers
 - Copy Headers as JSON
 - Copy Header Names
 - 如果点中具体 header 行，最好还能 Copy This Header
 - Request Body 卡片
 - Copy Body
 - Pretty Copy JSON
 - Copy as Raw Text
 - Save Body As…
 - cURL 卡片
 - Copy cURL
 - Send Again

这样即使用户鼠标已经停在某个 section 上，也不用回顶部。

3. 中间 Network 列表行：快速操作

你现在 PulseNetworkRowView 已经有 .contextMenu，里面只有 blacklist + delete。这里非常适合补高频项：

 - Copy URL
 - Copy cURL
 - Send Again
 - Copy Headers
 - Copy Query Parameters
 - Divider
 - Add to Blacklist
 - Delete Request

这层适合“我还没想看 detail，只想拿这个请求去 Bruno 试一下”。

-------------------------------------------------------------------------------------------------------

快捷键建议只给最高频动作，不要每个复制项都配。
推荐这几个就够了：

 - ⌘⇧U — Copy URL
 - ⌘⇧P — Copy Query Parameters
 - ⌘⇧H — Copy Headers
 - ⌘⇧B — Copy Body
 - ⌘⇧C — Copy cURL
 - ⌘⇧R — Send Again

不要把这些 shortcut 直接绑在零散按钮上，最好在 logViewerApp.swift 里加 .commands，做成一个 Request菜单，针对当前选中的 network request 生效。这样无论焦点在列表还是Inspector，只要有选中的请求，快捷键都稳定。

-------------------------------------------------------------------------------------------------------

数据格式上，Bruno 友好度最关键的是“不要只复制一大坨字符串”。
建议每一项都提供最适合粘贴的格式：

 - Copy URL
 纯完整 URL
 - Copy Query Parameters
 默认给这种最易人工拆分的格式：
 page=1
 sort=desc
 keyword=apple
 ``` 再补一个 JSON 版本：
 ```json
 {
   "page": "1",
   "sort": "desc",
   "keyword": "apple"
 }
 - Copy Headers
 默认：
 Authorization: Bearer xxx
 Content-Type: application/json
 X-Trace-Id: abc
 ``` 再补 JSON 版本：
 ```json
 {
   "Authorization": "Bearer xxx",
   "Content-Type": "application/json",
   "X-Trace-Id": "abc"
 }
 - Copy Body
 优先输出原始 body；如果是 JSON，再提供 pretty 版本

这套格式非常适合你“复制到 Bruno 的 URL / Params / Headers / Body 区块里”。
